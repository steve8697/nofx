# Skill: context

# 数据解读指南

## 技术指标说明

**EMA (指数移动平均线)**: 趋势方向
- 价格 > EMA → 上升趋势
- 价格 < EMA → 下降趋势

**MACD (移动平均收敛发散)**: 动量
- MACD > 0 → 看涨动量
- MACD < 0 → 看跌动量

**RSI (相对强弱指数)**: 超买/超卖
- RSI > 70 → 超买（可能回调）
- RSI < 30 → 超卖（可能反弹）
- RSI 40-60 → 中性区

**ATR (平均真实波幅)**: 波动性
- 高 ATR → 高波动（止损需更宽）
- 低 ATR → 低波动（止损可收紧）

**成交量 Z-Score (Volume Z-Score)**: 当前成交量与 10% 去尾均值的相对偏离度（以去尾标准差为单位）
- Z-Score >= 1.5 → 强成交量动能（Strong Volume Momentum），表明成交量发生异常性爆发，强烈支持顺势突破。
- -0.5 <= Z-Score < 1.5 → 正常成交量（Normal Volume），表明成交量在正常合理波动范围内，流动性健康。
- Z-Score < -0.5 → 缩量/冷清（Volume Contraction），表明市场活跃度低。顺势追高/追空需谨慎，建议使用小仓位。除非是极低位的关键支撑反弹（做多）或极高位阻力回落（做空），且有大周期趋势共振。
- Z-Score < -1.5 → 成交量偏低（Low Volume），流动性较差，仅允许微仓位开仓（1% 风险预算），不可使用大仓位。
- Z-Score < -3.0 → 极度萎缩（Extreme Contraction），表明流动性枯竭，禁止任何方向的开仓。

**持仓量 (Open Interest)**: 市场参与度
- 上涨 + OI 增加 → 强势上涨
- 下跌 + OI 增加 → 强势下跌
- OI 下降 → 趋势减弱
- **OI 变化 >+5%** → 真实突破确认（V5.5.1 强调）

**资金费率 (Funding Rate)**: 市场情绪
- 正费率 → 看涨（多方支付空方）
- 负费率 → 看跌（空方支付多方）
- 极端费率 (>0.01%) → 可能反转信号

## 数据顺序 (重要)

⚠️ **所有价格和指标数据按时间排序: 旧 → 新**

**数组最后一个元素 = 最新数据点**
**数组第一个元素 = 最旧数据点**
